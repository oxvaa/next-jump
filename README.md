# NEXT Jump v0.1

Minimal endless-jumper prototype designed first for iPhone/mobile Safari.

## Controls
- Hold left half of the screen = move left
- Hold right half = move right
- Character jumps automatically
- Desktop: Arrow keys / A + D

## GitHub Pages
Upload the contents of this folder to a GitHub repository, then enable GitHub Pages from the repository's default branch root.

## Files
- `index.html` — complete game
- `manifest.webmanifest` — installable PWA metadata
- `sw.js` — offline cache
- `icon-180.png`, `icon-512.png` — app icons
