# NEXT Jump v0.2

Precision-touch physics update for iPhone/mobile Safari.

## Controls
- Touch anywhere in the playfield and drag horizontally.
- The character follows the actual X position and speed of your finger.
- Release to let horizontal momentum settle naturally.
- Character jumps automatically.
- Desktop: Arrow keys / A + D.

## v0.2 changes
- Replaced left/right half-screen controls with continuous finger tracking.
- New spring-like horizontal steering with capped acceleration.
- Removed edge teleporting; player now stops naturally at screen edges.
- Tuned gravity, jump height, platform spacing, widths and camera feel.
- Added a subtle touch-position guide.
- Updated service worker to prefer fresh navigation so new builds do not get stuck behind the v0.1 cache.
